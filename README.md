# Open Source Wiki
Compilation of data for Open Source

## Creating an Open Source Distro

This repository also contains a plan for an open source distribution that
bundles popular tools. The idea is to collect free and open source software in
a single place for easy installation and reference.

### Goals

1. Identify widely used open source tools.
2. Provide setup scripts and configuration guidelines.
3. Document the licenses for each package.
4. Include popular AI frameworks such as TensorFlow, PyTorch, and Transformers.
5. Gather open source voice generation tools like Mozilla TTS, Coqui TTS, MaryTTS, and eSpeak.

Contributions are welcome for additional tools and improvements.
